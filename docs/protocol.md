# シリアル通信プロトコル仕様 (MVP)

## 通信設定
- インターフェース: USB Type-C (UART)
- ボーレート: `115200` bps
- データ形式: UTF-8 テキスト（改行コード `\n` 区切り）

## コマンド一覧 (Host -> Firmware)

| コマンド文字列 | 作業モード | 照明の挙動（目標状態） |
| :--- | :--- | :--- |
| `MODE:PC\n` | PCモニター作業中（正面） | 昼白色（約4500K）・中輝度・均一なアンビエント面発光 |
| `MODE:DESK\n` | 手元作業中（下向き） | 昼光色（約5800K）・高輝度・下側を強めたタスク配光 |
| `MODE:AWAY\n` | 離席中（人物未検出） | 緩やかにフェードアウトして消灯（待機） |

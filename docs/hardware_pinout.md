 # ハードウェア仕様・ピンアサイン (ESP32-LEDPRO-R2 + P4 64x32)

  ## 1. パネル・コントローラ基本仕様
  - **LEDパネル**: P4 RGB LEDマトリックスパネル 64×32ドット（256mm×128mm, 1/16スキャン, シフトレジスタ `FM6124` 系）
  - **コントローラ**: MicroFan `ESP32-LEDPRO-R2` (ESP32-WROOM-32E, 16MB Flash)
  - **外部電源**: DC 5.0V 4.0A（センタープラス、`PWR1` ジャック入力 → ネジ端子台経由でパネル中央4ピン電源ソケットへ給電）
    - ネジ端子極性: `PWR1` 側 = `5V`（赤線）、基板角/`CN2` 側 = `GND`（黒線）
  - **クロック位相補正**: `FM6124` ドライバとのエッジ整合のため `mxconfig.clkphase = false` が必須（`true` だと左端 `x=0` の色が右端 `x=63` に1列回り込む）。

  ## 2. GPIO ピン割り当て一覧

  | 区分 | 信号名 | ESP32 GPIO | 備考 |
  | :--- | :--- | :---: | :--- |
  | **HUB75 データ** | `R1` / `G1` / `B1` | `25` / `26` / `27` | 上半分 RGB（色順入れ替えなし） |
  | **HUB75 データ** | `R2` / `G2` / `B2` | `14` / `12` / `13` | 下半分 RGB（色順入れ替えなし） |
  | **HUB75 アドレス** | `A` / `B` / `C` / `D` / `E` | `23` / `19` / `5` / `17` / `-1` | 縦32ドット（1/16スキャン）のため `E` 未使用 |
  | **HUB75 制御** | `LAT` / `OE` / `CLK` | `4` / `15` / `16` | |
  | **内蔵センサー** | 明るさセンサ (`PHOTO TR`) | `36` | アナログ入力専用ピン (`ADC1_CH0`) |
  | **内蔵センサー** | I2C (`SDA` / `SCL`) | `21` / `22` | 温湿度 `AHT20`・加速度 `KXTJ3-1057` 共通 |
